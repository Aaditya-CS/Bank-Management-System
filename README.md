# Bank Management System
A project made to simulate the working of a bank management system, made with Python and MySQL. This code was written in Python 3.7.0 using the IDLE editor, and MySQL 8.0 using the command client.

Features of the present code :

1. Allows the user to create new accounts which are stored in a database, and login with them.
2. Users may deposit, withdraw, and transfer money from their own accounts and send it to other users, respectively.
3. Users can view their previous transactions, and view the amount changed during the past transactions in a neat graph.

Modules used :

1. MySQL.connector (Connectivity between Python and MySQL)
2. tkinter (Graphical user interface)
3. matplotlib (Plotting Graphs)

The project is done with the usage of databases, hence the creation of associated databases and tables is required to run the program.
An extensive amount of user-defined-functions have been used in the program.
